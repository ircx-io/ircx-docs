# Security

## Scope

This policy covers this repository (its content, checks, tests and CI) and the Help pages built from it at https://ircx.io/help.

Other ircx.io services are out of scope. This repository does not take reports about them. Please do not disclose a problem with another ircx.io service in a public issue, pull request or discussion here.

## Reporting a vulnerability

Report it privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability** (https://github.com/ircx-io/ircx-docs/security). Do not open a public issue.
